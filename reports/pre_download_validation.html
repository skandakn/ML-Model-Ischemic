1. Early-Warning Label Pipeline Validation (20 Pilot Cases)

1.1 Temporal Architecture Definition

The prospective early-warning prediction pipeline evaluates sliding windows with the following non-overlapping temporal segments: * Observation Window ($T_{\text{obs}}$): 300 seconds (5 minutes) of continuous multimodal physiological inputs (ECG_II, PLETH, SpO2). * Prediction Gap ($T_{\text{gap}}$): 300 seconds (5 minutes) of enforced lead time. No model features or target information from this interval may be used at inference time. * Target Horizon ($T_{\text{target}}$): 300 seconds (5 minutes) during which the clinical event is evaluated. * Stride: 60 seconds (1 minute).

Timeline Progression (Total Span = 900 seconds / 15 minutes):
|-------------------|-------------------|-------------------|
|  T_obs (300 s)    |  T_gap (300 s)    | T_target (300 s)  |
|  [t, t + 300)     |  [t+300, t+600)   | [t+600, t+900)    |
|  Model Predictors | Enforced Lead-Time| Clinical Target   |
|-------------------|-------------------|-------------------|

1.2 Criteria for Valid Positive and Negative Examples

  • Valid Early-Warning Positive Example (y = 1): 1. No sustained ST event in $T_{\text{obs}}$ ($\text{max_consecutive}(ST_II \le -1.0\text{ mm}) < 60\text{ s}$). If the patient is already ischemic in $T_{\text{obs}}$, it is not an early warning; the event is already in progress. 2. Observation window ends; an enforced 5-minute prediction gap ($T_{\text{gap}}$) elapses. 3. A verified sustained ST event occurs inside the target window ($\text{max_consecutive}(ST_II \le -1.0\text{ mm}) \ge 60\text{ s}$ inside $T_{\text{target}}$).
  • Valid Negative Control Example (y = 0): 1. $T_{\text{obs}}$ contains valid physiological data. 2. $T_{\text{target}}$ remains strictly within normal baseline limits ($\min(ST_II) > -0.8\text{ mm}$ and $\max(ST_II) < +0.8\text{ mm}$).
  • Indeterminate Exclusions: 1. Insufficient data coverage ($< 30$ valid numeric ST samples in $T_{\text{obs}}$ or $T_{\text{target}}$). 2. Ambiguous buffer zone: Target window reaches $-1.0\text{ mm} < \min(ST_II) \le -0.8\text{ mm}$ or brief non-sustained excursions ($< 60\text{ s}$). Excluded from binary classification to prevent label noise.

1.4 Critical Clinical and Mathematical Analysis of Pilot Sparsity

  1. Severe Class Sparsity in Unselected Pilot: In the 20-case unselected pilot, exactly 1 patient (Case 1) experienced sustained intraoperative myocardial ischemia. When evaluated under the 5-minute early-warning architecture, this single episode yields only 5 valid warning windows (starting at minutes 164.0, 165.0, 166.0, 167.0, and 168.0) against 3,288 negative windows (positive class prevalence: 0.15%).
  2. Detailed Dynamic in Case 1: * The 186-second sustained episode begins at $t = 10,663\text{ s}$ (minute 177.7) and ends at $t = 10,848\text{ s}$ (minute 180.8). * For window start $t = 164.0\text{ min}$ ($9,840\text{ s}$): $T_{\text{obs}} = [164, 169)\text{ min}$ (clean baseline, ST min $-0.6\text{ mm}$), $T_{\text{gap}} = [169, 174)\text{ min}$ (lead time, clean), $T_{\text{target}} = [174, 179)\text{ min}$ (contains first 78s of event) $\implies$ VALID POSITIVE. * For window start $t = 168.0\text{ min}$ ($10,080\text{ s}$): $T_{\text{obs}} = [168, 173)\text{ min}$ (clean), $T_{\text{gap}} = [173, 178)\text{ min}$ (brief 18s transient dip), $T_{\text{target}} = [178, 183)\text{ min}$ (contains 168s of event) $\implies$ VALID POSITIVE. * For window start $t = 169.0\text{ min}$ ($10,140\text{ s}$): The sustained episode has already started in $T_{\text{gap}}$ (78s consecutive inside gap), and continues into $T_{\text{target}}$ (108s). If early warning requires event onset in $T_{\text{target}}$, this window is excluded; if it requires event presence in $T_{\text{target}}$, it yields a 6th positive window.
  3. Integrity Rule on Prediction Gap:

    [!CAUTION] We must NOT reduce or remove the 5-minute prediction gap simply to artificially inflate positive counts. Eliminating the gap collapses the problem into concurrent diagnosis (detecting an event while it is already underway), which invalidates the clinical objective of BeatAhead: providing genuine advance warning so anesthesiologists can intervene before irreversible myocardial injury occurs. The correct, scientifically valid solution is cohort expansion enriched for cardiovascular risk (Cohort A).

5. Reconsideration of the ST Feature Decision & Future Ablation Plan

Rather than indiscriminately purging all ST metrics or introducing target leakage, ST data are classified into three distinct temporal categories:

5.1 Three-Tier Classification of ST Information

  1. Category A — Future-Target ST Data (PROHIBITED): * Any ST observation occurring within the prediction gap ($T_{\text{gap}}$) or target window ($T_{\text{target}}$). * Rule: Absolutely forbidden from model inputs. Inclusion constitutes direct label leakage.
  2. Category B — Pre-Event ST Data inside $T_{\text{obs}}$ (POTENTIALLY VALID PREDICTOR): * Descriptive metrics of ST deviation computed purely within the 5-minute observation window $T_{\text{obs}}$ (e.g., mean ST, minimum ST, ST standard deviation, ST slope/trajectory). * Clinical Justification: In practice, early micro-shifts or minor downward trends in the ST segment often precede full $\ge 60\text{ s}$ diagnostic depression. Evaluating whether these subtle changes have predictive value is clinically meaningful.
  3. Category C — Baseline-Relative ST Features (POTENTIALLY VALID PREDICTOR): * Normalized ST shifts relative to the patient's individual resting baseline established during early stable anesthesia ($\Delta\text{ST} = \text{ST}{\text{obs}} - \text{ST}{\text{baseline}}$). * Clinical Justification: Adjusts for pre-existing bundle branch blocks, left ventricular hypertrophy, or benign non-ischemic baseline elevations.
