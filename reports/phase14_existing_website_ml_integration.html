7. Model Output & ISI Engine Integration

  • Model Operating Threshold: Exactly 0.156742 (derived from $F_1$ optimization during Phase 5).
  • Model Output: $p_{\text{model}} \in [0, 1]$.
  • Piecewise Sigmoidal Transformation: $$E_{\text{model}}(p) = \begin{cases} 0.5 \times \left(\frac{p}{\tau}\right)^{\gamma_1} & \text{if } p < \tau \ 1 - 0.5 \times \left(\frac{1 - p}{1 - \tau}\right)^{\gamma_2} & \text{if } p \ge \tau \end{cases}$$ Where $\tau = 0.156742$, $\gamma_1 = 1.4$, $\gamma_2 = 4.0$. At $p = \tau = 0.156742$, $E_{\text{model}} \equiv 0.500000$ exactly.
  • Product Score Composition: $$\text{ISI} = \text{clamp}{[0, 100]}\left(40.0 + 60.0 \times \left(0.45 E{\text{model}} + 0.30 D_{\text{auto}} + 0.25 D_{\text{perf}} + M_{\text{trend}}\right)\right)$$
  • State Machine Integration:
  • Normal / Stable: $p_{\text{model}} < 0.156742$, clean signals, stable trajectory ($\text{ISI} \approx 35–45$).
  • Elevated Model Evidence: $p_{\text{model}} \ge 0.156742$ ($E_{\text{model}} \ge 0.50$), triggering early-warning alert badge ($\text{ISI} \approx 60–80$).
  • Elevated ISI Trend: Rising multi-source trajectory without single-threshold breach.
  • Insufficient Signal Quality: Overall SQI $< 0.35$ (motion artifact scenario).
  • Baseline Establishing: Monitoring time $< 600\text{ s}$.

10. Simulated-Input Demonstration Behavior

When running in simulated demonstration mode: 1. Normal Scenario: - Simulated vitals remain normative ($HR \approx 68\text{ bpm}$, $SDNN \approx 48\text{ ms}$, $ST \approx +0.08\text{ mm}$). - 26-feature Matrix A vector produces $p_{\text{model}} \approx 0.005–0.030 < 0.156742$. - ISI gauge reads $\approx 35–42$ ("Optimal / Low Risk"), state displays NORMAL (< 0.156742). 2. Stress Event Scenario: - Acute ischemic profile triggers progressive ST sagging ($ST \rightarrow -1.65\text{ mm}$), tachycardia ($HR \rightarrow 94\text{ bpm}$), and PAT delay ($PAT \rightarrow 285\text{ ms}$). - 26-feature Matrix A vector produces $p_{\text{model}} \approx 0.32–0.45 \ge 0.156742$. - ISI gauge rises to $\approx 68–82$, state switches to ALERT (≥ 0.156742), triggering the early-warning advisory banner. 3. Motion Artifact Scenario: - Severe IMU motion degrades SQI ($Q_{\text{ecg}} < 0.50$, $Q_{\text{ppg}} < 0.50$). - Signal quality gate enforces Insufficient Signal Quality, preventing false alarm precision.

11. Remaining Production Limitations

  1. Simulated Input Prototype: The website currently runs on simulated physiological streaming for demonstration; real wearable hardware streaming (via Bluetooth LE / WebSocket) requires physical wearable sensor drivers.
  2. Cloud Run Provisioning: The containerized ML service is fully packaged and ready (Dockerfile, requirements.txt), but live deployment to Google Cloud Run remains blocked pending external GCP CLI setup and credentials (as documented in Phase 13).
  3. Investigational Status: BeatAhead is an investigational research prototype for surgical/clinical monitoring early-warning trend analysis and is not FDA approved for diagnostic use.
